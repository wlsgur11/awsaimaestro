# AWS AI 마에스트로 해커톤

부산대학교 AWS AI 마에스트로 해커톤 안내 웹사이트입니다.

## 구성
- `dist/index.html`: 행사 소개, 과제, 일정, 시상 및 FAQ
- `dist/style.css`: 반응형 디자인
- `dist/script.js`: 프로그램 탭 인터랙션

## 배포
Vercel에서 이 저장소를 연결하면 `vercel.json` 설정에 따라 `dist` 폴더를 정적 사이트로 배포합니다. 별도의 빌드나 환경 변수는 필요하지 않습니다.

## 현재 안내
- 부트캠프 참여 학부생 30명 / 7개 팀 내외 / 7개 내외 주제
- 총상금 1,000만 원 / 대상 200만 원 (대상 1팀, 최우수상 2팀, 우수상 4팀)
- 기타 등급별 상금 및 참가 신청 링크: 추후 안내
